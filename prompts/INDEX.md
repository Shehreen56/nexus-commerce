# NEXUS-COMMERCE — AI Prompt Index

## Purpose
This directory documents AI-assisted development work for the NEXUS-COMMERCE capstone project. It provides an organized record of prompts, their intended purpose, and the development outcomes.

## Prompt Log Authenticity
- **Original:** Exact prompt text retained from the original development conversation.
- **Reconstructed:** Recreated from the development conversation where the exact original wording was unavailable.
- Reconstructed prompts are not presented as verbatim original prompts.

## Prompt Categories

| File | Category | Purpose |
|---|---|---|
| `01-project-planning.md` | Project Planning | Understand requirements, scope, and architecture |
| `02-frontend-development.md` | Frontend Development | Build storefront, product catalog, search, filters, and cart |
| `03-backend-development.md` | Backend Development | Implement APIs, database, orders, and inventory |
| `04-admin-crm.md` | Admin and CRM | Implement admin authentication, dashboard, customers, and order management |

| `08-documentation-and-deployment.md` | Documentation and Deployment | Prepare project documentation, GitHub, and hosting |

## Prompt Documentation Format

Each prompt record should contain:

1. Prompt title
2. Authenticity label (Original or Reconstructed)
3. Prompt text
4. Purpose
5. AI-assisted development outcome
6. Verification or testing evidence

## Verification
All documented prompts and outcomes should be checked against the actual project implementation. No fabricated original prompt history or unsupported completion claims should be included.
